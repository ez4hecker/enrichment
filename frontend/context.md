# GrowthInfi UI Context

## Overview
This project is a Next.js App Router application ("GrowthInfi"), built primarily using components generated by a ditto.site clone (originally from `app.sendr.io`).

## Directory Structure
- The main application lives in `C:\growthInfi\ui\frontend`.
- Original ditto clone exports are preserved in the parent directory (`C:\growthInfi\ui\sendr-clone-step1` through `step11`).
- `combine.js` in the root was previously used to merge these steps.

## Next.js App Structure (`src/app`)
- `/`: The root page, containing the login view (Sendr clone).
- `/dashboard`: A layout wrapping the main authenticated app. Contains nested routes:
  - `/dashboard/custom-operations`
  - `/dashboard/new-job`
- `/step11`: Another cloned page route, retaining its own distinct components, sections, and svgs.
- `layout.tsx`: Root layout setting global properties, font `Rethink_Sans`, and title "GrowthInfi".

## Styling & Assets
- `globals.css` and `ditto.css` are used for global styling, carrying over the fidelity of the cloned application. Tailwind CSS is configured.
- `public/logo.png` is used as the app icon.
